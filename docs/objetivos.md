Objetivos del proyecto EspacioYa

Objetivo general

Desarrollar una aplicación web en Python, utilizando la arquitectura Modelo-Vista-Controlador (MVC), que permita administrar espacios físicos, usuarios y reservas, evitando conflictos de horarios y facilitando la consulta de disponibilidad.

Objetivos específicos

1. Implementar las funciones de crear, consultar, actualizar y eliminar espacios, usuarios y reservas.
2. Validar los horarios para evitar reservas duplicadas o superpuestas.
3. Diseñar un calendario que permita visualizar la disponibilidad de los espacios.
4. Aplicar la arquitectura MVC para organizar adecuadamente el sistema.
5. Utilizar los principios de programación orientada a objetos.
6. Documentar el proceso de desarrollo y las decisiones técnicas del proyecto.
