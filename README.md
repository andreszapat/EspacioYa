EspacioYa – Sistema de Reservas de Espacios

Descripción del proyecto

EspacioYa es un proyecto académico desarrollado para la asignatura Lenguajes de Programación de la Universidad Santiago de Cali.

Su objetivo es desarrollar un sistema web que permita administrar espacios físicos como aulas, salas de reuniones, laboratorios y auditorios, facilitando la consulta de disponibilidad y la realización de reservas.

El sistema busca evitar que dos personas reserven un mismo espacio en horarios que se crucen.

Objetivo general

Desarrollar una aplicación web en Python, utilizando la arquitectura Modelo-Vista-Controlador (MVC) y una base de datos SQLite, para gestionar usuarios, espacios y reservas.

Funcionalidades principales

* Registrar y administrar espacios físicos.
* Gestionar usuarios según sus roles.
* Consultar disponibilidad de espacios.
* Crear y cancelar reservas.
* Evitar reservas duplicadas o conflictos de horarios.
* Visualizar la disponibilidad mediante un calendario.
* Validar los permisos correspondientes a cada usuario.

Roles del sistema

Estudiante: puede consultar espacios disponibles, realizar reservas y cancelar sus propias reservas.

Docente: puede consultar disponibilidad, realizar reservas, registrar espacios y modificar los espacios que haya creado.

Administrativo: puede gestionar usuarios, espacios y reservas de todo el sistema.

Tecnologías propuestas

* Python 3
* Flask
* SQLite
* HTML y CSS
* JavaScript
* Git y GitHub

Arquitectura

Se utilizará el patrón Modelo-Vista-Controlador (MVC), que permite separar los datos, la lógica del sistema y la interfaz de usuario.

Metodología de trabajo

El proyecto se desarrollará mediante una metodología ágil, combinando Scrum y Kanban.

Se organizará en cuatro sprints:

1. Configuración del proyecto y gestión de espacios.
2. Autenticación y administración de usuarios.
3. Implementación de reservas y validación de horarios.
4. Pruebas, mejoras y documentación final.
